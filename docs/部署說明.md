# 新版進銷存系統部署說明

本文說明如何將 `SmartIMS.Web` 部署到 Windows/IIS，並建立 SQL Server 資料庫。

## 1. 系統需求

- Windows Server 或 Windows 10/11
- IIS，並啟用 ASP.NET Core Hosting Bundle
- .NET 10 Runtime 或 Hosting Bundle
- SQL Server 2019 以上，或可連線的 SQL Server 執行個體
- 部署帳號需具備網站目錄讀取權限
- 首次建置資料庫的 SQL 帳號需具備 `CREATE DATABASE`、`CREATE TABLE`、`ALTER TABLE`、`CREATE INDEX` 權限

## 2. 專案結構

- 原始碼：`SmartIMS.Web/`
- 已發佈網站檔案：`Site/`
- SQL 建置腳本：`database/create_smartims_database.sql`
- 主要設定來源：環境變數

程式啟動時會執行 `DatabaseBootstrapper.EnsureAsync()`，可自動建立資料庫、資料表、索引、外鍵與預設資料。若正式環境希望先由 DBA 建庫，請先執行本文提供的 SQL 腳本。

## 3. 建立 SQL Server 資料庫

使用 SSMS 開啟 `database/create_smartims_database.sql`。

若使用 SSMS，請先啟用：

```text
Query -> SQLCMD Mode
```

如需改資料庫名稱，修改腳本第一行：

```sql
:setvar DatabaseName "SmartIMS_NewVersion"
```

執行後會建立：

- 資料庫：`SmartIMS_NewVersion`
- 使用者表：`dbo.AppUser`
- 權限表：`dbo.AppPermission`
- 使用者權限表：`dbo.UserPermission`
- 系統設定表：`dbo.SystemSetting`
- 清單偏好設定表：`dbo.UserListViewSetting`
- 稽核表：`dbo.AuditLog`
- 預設管理員：`Admin`

預設管理員密碼不直接寫在 SQL 腳本內。第一次啟動網站時，若 `Admin.PasswordHash` 為空，程式會使用 `SMARTIMS_ADMIN_PASSWORD` 環境變數設定密碼；若未設定，預設為 `admin`。

## 4. 環境變數設定

建議在 IIS Application Pool 或系統環境變數中設定：

```powershell
setx DB_HOST "localhost"
setx DB_PORT "1433"
setx DB_NAME "SmartIMS_NewVersion"
setx DB_USER "smartims_user"
setx DB_PASSWORD "your_password"
setx DB_ENCRYPT "false"
setx DB_TRUST_SERVER_CERT "true"
setx SMARTIMS_ADMIN_PASSWORD "change_this_password"
```

也可以用完整連線字串：

```powershell
setx MSSQL_CONNECTION_STRING "Server=localhost;Database=SmartIMS_NewVersion;User ID=smartims_user;Password=your_password;Encrypt=False;TrustServerCertificate=True;"
```

若 `DB_USER` 或 `DB_PASSWORD` 未設定，程式會改用 Windows Integrated Security。

## 5. 發佈網站

在專案根目錄執行：

```powershell
dotnet publish SmartIMS.Web\SmartIMS.Web.csproj -c Release -o Site
```

確認 `Site/` 內包含：

- `SmartIMS.Web.dll`
- `SmartIMS.Web.exe`
- `web.config`
- `appsettings.json`
- `wwwroot/`

## 6. IIS 部署

1. 安裝 ASP.NET Core Hosting Bundle。
2. 建立 IIS Site，例如 `SmartIMS`。
3. Physical path 指向 `E:\新版進銷存系統\Site`。
4. Application Pool 設定：
   - .NET CLR Version：`No Managed Code`
   - Pipeline mode：`Integrated`
5. 設定網站或 Application Pool 的環境變數。
6. 確認 Application Pool identity 對 `Site/` 具有讀取權限。
7. 若要上傳 Logo 或登入圖，確認 `Site/wwwroot/uploads/branding` 可寫入。
8. 重新啟動網站。

## 7. 首次登入

預設帳號：

```text
Admin
```

密碼來源：

- 優先使用 `SMARTIMS_ADMIN_PASSWORD`
- 未設定時為 `admin`

首次登入後請立即修改預設密碼或透過資料庫更新密碼流程重設。

## 8. 驗證項目

部署後請檢查：

- 網站首頁可開啟
- 可使用 `Admin` 登入
- 使用者管理頁可開啟
- 權限設定頁可開啟
- 品牌設定可儲存
- SQL Server 內有 `AppUser`、`AppPermission`、`SystemSetting` 等資料表

## 9. 常見問題

### 連線資料庫失敗

檢查 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USER`、`DB_PASSWORD` 或 `MSSQL_CONNECTION_STRING` 是否正確。

### SSL 或憑證錯誤

內部測試環境可設定：

```powershell
setx DB_ENCRYPT "false"
setx DB_TRUST_SERVER_CERT "true"
```

正式環境建議使用可信任憑證並啟用加密。

### 權限不足無法自動建庫

由 DBA 先執行 `database/create_smartims_database.sql`，再讓網站使用只具備日常讀寫權限的帳號連線。

### 預設密碼不是預期值

只有當 `dbo.AppUser.PasswordHash` 為空時，程式啟動才會套用 `SMARTIMS_ADMIN_PASSWORD`。若已經有密碼雜湊，請透過後台或資料庫流程重設。

## 客戶資料管理

客戶頁面使用 `dbo.Customer`，不再使用前端示範資料。畫面的「公司名稱」、表單欄位 `customerName` 與資料模型 `CustomerName` 對應資料庫 `dbo.Customer.CustomerName`（欄位說明為「公司名稱」）；新增存檔時自動產生 `CustomerCode`，格式為 `C`＋5 碼流水號（`C00001`～`C99999`）。公司地址對應 `CompanyAddress`，送貨地址對應 `DeliveryAddress`；報價單的客戶地址延續原有來源，改讀 `CompanyAddress`。

既有資料庫可執行以下指令補齊客戶欄位（請依環境修改伺服器及資料庫名稱）：

```powershell
sqlcmd -S 'localhost\SQLEXPRESS' -E -C -b -d SmartIMS_NewVersion -i database\customer_management.sql
```

網站啟動也會自動補齊相同欄位。刪除客戶會將 `IsActive` 設為 0，保留歷史單據。客戶明細區會標示「新增客戶｜尚未存檔」或「編輯既有客戶」。新增、複製或修改後可直接按明細區的「存檔」；工具列「修改」也保留存檔功能。按「取消」會還原既有客戶或取消新增。搜尋不會取代新增草稿，切換客戶前若有未存檔內容會提示確認。Email 可留白。操作需具備對應客戶頁面及新增、修改、刪除權限。

## 商品與材質資料管理

商品管理頁已使用 `dbo.Product`，材質管理頁使用 `dbo.ProductMaterial`。商品的 `ProductMaterialID` 以外鍵連結材質，材質可不指定；厚度、長度、寬度保留文字格式（例如 `2.0mm`）。規格與單價分別使用既有 `Specification`、`UnitPrice`，可直接供報價單選用。

既有資料庫升級指令：

```powershell
sqlcmd -S 'localhost\SQLEXPRESS' -E -C -b -d SmartIMS_NewVersion -i database\product_management.sql
```

網站啟動會自動補齊相同結構。商品編號及材質編碼在啟用資料中不可重複；單價不可為負數，最多兩位小數。商品與材質頁提供「儲存」按鈕，也保留既有工具列操作及權限。商品停用後不再出現在新增報價的商品選單中，但保留歷史明細。仍被啟用商品使用的材質不可刪除。預設材質只在缺少時建立，重啟網站不再覆寫使用者修改或停用的材質。

客戶產號參數存於 `dbo.NumberSequence`：`SequenceKey=CUSTOMER`、`Prefix=C`、`PaddingLength=5`，`CurrentValue` 為最後使用的流水號。客戶明細的 `customerCode` 為唯讀欄位，新增與複製時不預占編號，成功存檔後才顯示。編號具有唯一索引；新增與取號使用同一筆交易，失敗時回復流水號，停用客戶不回收編號。

既有長編號可使用 `database/customer_numbering.sql` 升級，網站啟動亦會自動執行相同程序。升級保留現有合法編號，依 CustomerID 順序轉換舊編號，並同步報價與銷售單的客戶編號快照；客戶主鍵及其他單據內容不變。執行前請備份客戶舊編號。

客戶明細提供「銀行名稱」（BankName，最多 100 字）、「公司地址」（CompanyAddress，最多 500 字）與「送貨地址」（DeliveryAddress，最多 500 字），皆可留白。兩組地址分開儲存。網站啟動時會自動升級欄位，也可執行 database/customer_management.sql 更新既有資料庫。
