## 功能

- 「銷售管理 → 訂購單」沿用報價單版型，支援列表、搜尋／排序、明細檢視、新增、修改、複製及作廢。
- 使用既有 `SalesOrder`／`SalesOrderItem`，報價轉單後直接開啟訂購單；需要報價修改及訂購單新增權限。
- 已作廢、非 Confirmed 狀態或已有出貨數量的訂單不可改寫；複製產生新訂單，不複製來源關聯及 PDF 附件。
- 每張訂購單支援一個 PDF 附件，最大 20 MB；檢查副檔名及 `%PDF-` 檔頭。選檔後按儲存才上傳，未選新檔會保留原附件。
- PDF 使用隨機檔名儲存，原始檔名另存資料庫；透過登入及訂購單頁面權限下載，不提供公開靜態連結。
- 訂單儲存失敗會清除此次新寫入的檔案。替換成功後舊檔保留於原目錄，不自動清除。

## 儲存目錄

「系統管理 → 公司形象 → 訂購單 PDF 儲存路徑」設定 `SALES_ORDER_PDF_DIRECTORY`。

預設 `App_Data/SalesOrders`，相對於網站的 ContentRoot；IIS 發佈時即位於部署網站目錄下。可改為絕對路徑；不得設於 `wwwroot`，避免附件被公開下載。儲存設定時會建立目錄並測試寫入權限。

IIS 應用程式集區執行帳號需要該目錄的讀取、建立與寫入權限。改路徑只影響新上傳檔案，既有附件依資料庫記錄的絕對路徑下載，沒有自動搬移。部署及備份時須保留附件目錄；若移至另一台主機，須一併搬移附件並處理既有路徑。
