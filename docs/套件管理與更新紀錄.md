# 套件管理與更新紀錄

## 套件資料位置

- 專案參考與目標框架：`SmartIMS.Web/SmartIMS.Web.csproj`（目前為 .NET 10）。
- 完整 NuGet 相依套件版本、相依關係及內容雜湊：`SmartIMS.Web/packages.lock.json`，須納入版本控制。
- 套件來源：NuGet 官方來源 `https://api.nuget.org/v3/index.json`。
- 此處保存套件宣告與鎖定資料；實際套件由 NuGet 還原下載，不將本機 NuGet 快取或 DLL 當成套件版本依據。

## 目前直接相依套件

| 套件 | 版本 | 用途與選版原因 |
| --- | --- | --- |
| Microsoft.Data.SqlClient | 7.0.1 | SQL Server 連線與資料存取。 |
| System.Security.Cryptography.Pkcs | 10.0.13 | 使用 .NET 10 對應修補版，明確發佈修補 DLL，覆蓋伺服器原有共用框架中的 PKCS 組件。 |

所有間接相依的實際版本請查閱鎖定檔，避免另維護容易過期的重複清單。

## 還原與驗證

在專案根目錄執行：

```powershell
dotnet restore SmartIMS.Web/SmartIMS.Web.csproj --locked-mode
dotnet build SmartIMS.Web/SmartIMS.Web.csproj -c Release --no-restore -warnaserror
dotnet list SmartIMS.Web/SmartIMS.Web.csproj package --vulnerable --include-transitive
```

新增、升級或移除套件後，先執行以下指令更新鎖定檔，再執行上述檢查：

```powershell
dotnet restore SmartIMS.Web/SmartIMS.Web.csproj --force-evaluate
```

每次變更均須更新直接套件清單並新增一筆下列紀錄。欄位包括日期、套件與版本變化、原因、驗證結果、部署狀態；日期使用 Asia/Taipei。漏洞掃描結果只代表檢查當時的套件資料來源。

### 2026-11-13 — 修正 PKCS 安全性警告

- 套件：`System.Security.Cryptography.Pkcs`，9.0.13 → 9.0.21。

- 原因：修正 NU1902 與 NU1903，分別對應 [CVE-2026-70162](https://github.com/advisories/GHSA-2fmv-rv2c-59x7) 與 [CVE-2026-84008](https://github.com/advisories/GHSA-846f-f764-76mx)。
- 驗證：Release 建置 0 警告、0 錯誤；包含間接相依的漏洞掃描未發現已知漏洞。
- 運作驗證：以獨立 SQL Server 測試資料庫啟動發佈程式，確認登入、登出、客戶、商品、材質、報價清單與新增頁、使用者、權限、品牌頁及靜態資源正常回應；客戶新增、修改、重新讀取與軟刪除成功，包含銀行名稱、收件地址及送貨地址分開儲存。測試伺服器與資料庫已清理。
- 驗證範圍：HTTP 與資料存取驗證，未進行完整瀏覽器互動測試或全部業務流程測試。
- 部署：已產生 `C:/ERP2/.security-fix-release` 發佈檔，尚未部署至 IIS。
- 後續補正：此版本雖使 NuGet 警告消失，但 .NET 10 發佈時排除了 9.x PKCS DLL，實際執行仍選用共用框架組件；不能僅憑套件掃描認定部署環境已修補。最終修正與部署見下方 10.0.13 紀錄。
