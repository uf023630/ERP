## 專案概況

ASP.NET Core MVC / .NET 10，使用 Microsoft.Data.SqlClient 存取 SQL Server。包含客戶、商品、材質、報價單、訂購單、PDF 存查、使用者與權限、品牌及系統設定。啟動時由 DatabaseBootstrapper 建立或更新資料庫結構。

## 已確認的程式問題

1. **高：停用帳號、重設密碼或撤銷權限，不會撤銷既有登入。** Program.cs 使用 8 小時且可滑動續期的 Cookie，未設定 ValidatePrincipal；AuthService 在登入時將權限寫入 claims，RequirePermissionFilter 只檢查 Cookie claims。AdminService 更新資料庫後，已登入的瀏覽器仍可使用舊身分與權限；持續使用時還可能續期。建議加入伺服器端帳號狀態與憑證版本驗證，密碼或權限變更後使舊憑證失效。此項為程式碼確認，未用正式帳號進行停用測試。
2. **中：合法的資料庫連線字串可能無法使用。** SqlConnectionFactory.ParseSegments 直接用分號切割，Password="abc;def" 會被截斷；Integrated Security=SSPI 也未被 ParseBoolean 接受。建議使用 SqlConnectionStringBuilder 解析完整字串並保留標準語意。此項為程式碼確認，未變更正式連線資訊。
3. **中：未設定管理員密碼時會建立可預測的預設密碼。** DatabaseBootstrapper.EnsureDefaultAdminPasswordAsync 在環境變數未設定且初始密碼為空時，使用 admin；AdminService 新增使用者缺少密碼時也有固定備援值。建議首次建立時要求明確提供密碼或使用一次性初始化流程。未確認正式系統目前是否仍使用預設密碼。
